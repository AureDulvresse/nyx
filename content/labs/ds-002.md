## Scénario

L'équipe sécurité de Nyx Corp veut un premier filtre automatique de détection de phishing basé sur le contenu des emails. Tu disposes d'un jeu d'entraînement étiqueté (`~/data/phishing_train.csv`, 15 emails classés `phishing`/`legitime`) et d'un jeu de test non étiqueté (`~/data/phishing_test.csv`, 3 emails) à classifier avec le modèle que tu auras entraîné.

## Objectifs

1. Charger le jeu d'entraînement et vectoriser le texte (sujet + extrait du corps) avec `TfidfVectorizer`
2. Entraîner un classifieur `MultinomialNB` (Naive Bayes) sur ces vecteurs et les étiquettes connues
3. Appliquer le modèle entraîné au jeu de test pour identifier l'email de phishing avec la plus grande confiance

## Indices

- Concatène le sujet et l'extrait du corps en un seul champ texte avant de vectoriser — le modèle a besoin de tout le signal disponible, pas seulement le sujet.
- `TfidfVectorizer` doit être **entraîné (fit)** uniquement sur le jeu d'entraînement, puis seulement **appliqué (transform)** sur le jeu de test — jamais l'inverse, sous peine de biaiser l'évaluation.
- Une fois les prédictions obtenues, la colonne `message_id` de l'email classé `phishing` avec la plus grande probabilité contient le flag à soumettre.

<TipCallout>
```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB

train = pd.read_csv("data/phishing_train.csv")
test = pd.read_csv("data/phishing_test.csv")

train["text"] = train["subject"] + " " + train["body_snippet"]
test["text"] = test["subject"] + " " + test["body_snippet"]

vectorizer = TfidfVectorizer()
X_train = vectorizer.fit_transform(train["text"])
X_test = vectorizer.transform(test["text"])

model = MultinomialNB()
model.fit(X_train, train["label"])
test["predicted"] = model.predict(X_test)
print(test[["message_id", "predicted"]])
```
</TipCallout>

<CehCallout>
Un modèle Naive Bayes entraîné sur seulement 15 exemples reste un jouet pédagogique — un vrai filtre anti-phishing en production s'entraîne sur des dizaines de milliers d'emails et combine plusieurs signaux (réputation du domaine expéditeur, en-têtes SPF/DKIM, URLs extraites) au-delà du seul contenu textuel.
</CehCallout>
